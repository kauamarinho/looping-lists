# Exercícios de Python

Este projeto reúne exercícios desenvolvidos para praticar os fundamentos da linguagem Python, com foco em **estruturas condicionais, operadores lógicos, estruturas de repetição e listas**.

As soluções dos exercícios estão disponíveis separadamente nos arquivos `.py` do projeto.

## Exercício 1 — Classificar transações bancárias

Desenvolver um programa para analisar transações bancárias e identificar situações que precisam de atenção, como transferências de valores elevados e operações de saque.

**Conceitos praticados:**
- `if`
- `elif`
- `else`
- Operador `and`
- Operadores de comparação
- Variáveis

## Exercício 2 — Verificar elegibilidade para promoção

Desenvolver um programa que determine se um funcionário está apto para receber uma promoção, considerando seu tempo de empresa e sua nota de avaliação.

**Conceitos praticados:**
- `if`
- `else`
- Operador `and`
- Operadores de comparação
- Condições booleanas

## Exercício 3 — Avaliar risco de atraso

Criar uma análise de risco para entregas considerando a distância, o clima e a zona de entrega. O programa deve identificar situações com maior possibilidade de atraso.

**Conceitos praticados:**
- `if`
- `else`
- Operador `and`
- Operador `or`
- Múltiplas condições
- Operadores de comparação

## Exercício 4 — Tratar falhas de sensores

Desenvolver um sistema simples para interpretar códigos de falha de sensores de uma linha de produção. Cada código e condição de temperatura pode resultar em uma ação diferente.

**Conceitos praticados:**
- `if`
- `elif`
- `else`
- Operador `and`
- Comparação de strings
- Comparação de valores numéricos
- Múltiplos caminhos de decisão

## Exercício 5 — Filtrar clientes satisfeitos

Percorrer uma lista de avaliações de clientes e identificar somente as notas maiores que 7, representando clientes satisfeitos.

**Conceitos praticados:**
- Listas
- `for`
- `if`
- Iteração
- Operadores de comparação

## Exercício 6 — Gerar lista de comissões

Criar uma sequência de valores de comissão entre 0 e 50 reais, aumentando os valores de 5 em 5.

**Conceitos praticados:**
- `range()`
- `list()`
- Sequências numéricas
- Definição de início, limite e passo

## Exercício 8 — Reorganizar fila de pedidos

Criar um programa para reorganizar uma lista de pedidos de acordo com a prioridade.

Se o pedido for urgente, ele deve ser inserido no início da fila. Caso não seja urgente, o programa deve substituir um pedido existente pelo novo pedido.

Também devem ser testados três cenários:

- Pedido urgente.
- Pedido não urgente com pedido a substituir existente.
- Pedido não urgente com pedido a substituir inexistente.

**Conceitos praticados:**
- Listas
- `if`, `elif` e `else`
- Operador `in`
- `insert()`
- `index()`
- Alteração de elementos por índice
